# Exam Score to Percentile Prediction System

## Overview
This project builds a machine learning pipeline to estimate exam percentile based on a student's marks and exam conditions. The system simulates exam data, cleans it, trains a regression model, and provides percentile predictions through an interactive interface.

The goal is to demonstrate the complete machine learning workflow including data generation, preprocessing, model training, visualization, and prediction.

## Features
- Synthetic dataset generation for exam performance
- Data cleaning and anomaly removal
- Machine learning model training using Gradient Boosting
- Data visualization and exploratory analysis
- Correlation analysis between exam features
- Regression analysis of marks vs percentile
- Interactive prediction interface

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## Machine Learning Model
Model Used:
- Gradient Boosting Regressor

Input Features:
- Marks
- Year
- Month
- Day
- Exam Shift

Output:
- Predicted Percentile Score

## Visualization
The project generates multiple visualizations including:
- Marks distribution histogram
- Percentile distribution by year
- Correlation heatmap
- Scatter plot of marks vs percentile
- Regression curve for model predictions

This project demonstrates practical implementation of:
- Data preprocessing and cleaning

- Machine learning regression models

- End-to-end ML workflow
